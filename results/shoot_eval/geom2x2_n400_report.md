## 0. 结论

**geomA 重训带来的策略增益是真实的，且在 n=400 上达到统计显著。**

| 量 | 值 |
|---|---|
| kill rate，base @ U(0,60) | **362/400 = 0.9050**，Wilson 95% [0.872, 0.930] |
| kill rate，geomA @ U(0,60) | **375/400 = 0.9375**，Wilson 95% [0.909, 0.957] |
| **配对差值** | **+3.25 pp** |
| **精确 McNemar（配对）** | **p = 0.0146 → 显著** ✅ |
| 非配对 Fisher（同数据） | p = 0.1146 → 不显著 |

**最有价值的一点：同一批数据，非配对检验 p=0.115 看不出来，配对检验 p=0.0146 看得出来。** 这是因为逐集结果落盘后才可能做配对 —— 评估脚本里那个 `episodes_detail` 改动就是这次能得出结论的直接原因。

同时必须重申：**最初的「87 → 95，+8 pp」仍然高估了策略增益约 2.5 倍。** 几何放宽本身贡献约 +4.5 pp（n=100 的 2×2 已分离出来），策略部分约 +3.25 pp。

## 1. 配对结果（已验证事实）

400 个 episode = seed 42…441，两个 arm 用**完全相同的 seed 与几何**，故逐集真配对。

| 配对状态 | 数量 |
|---|---|
| 两者都击杀 | 356 |
| 两者都未击杀 | 19 |
| **仅 geomA 击杀** | **19** |
| **仅 base 击杀** | **6** |
| 不一致对合计 | 25 |

- 不一致对中 **19/25 = 76% 偏向 geomA**
- 精确 McNemar 双侧 **p = 0.0146**
- 非配对参考：Newcombe 95% CI [−0.5, +7.1] pp；Fisher 双侧 p = 0.1146

按实测不一致率外推的样本量曲线（来自 `analyze_2x2_strata.py`）：

| n/组 | 不一致对 | 精确 McNemar p |
|---|---|---|
| 100 | 5 / 2 | 0.453 |
| 200 | 10 / 3 | 0.092 |
| 300 | 14 / 4 | 0.031 |
| **400（实测 19 / 6）** | **19 / 6** | **0.0146** |
| 600 | 28 / 9 | 0.003 |

⇒ n=400 正是跨越 p<0.05 的门槛，实测值比外推略好（因为不一致对的方向比预期更集中）。

## 2. 方法学校验（已验证事实）

**① 400 集的前 100 集与独立 100 集运行逐字段完全一致**（0 处差异 → bit-identical，双方均为 91 次击杀）。400 集是 100 集的严格超集，评估流程完全确定性。

**② 两个 arm 的场景完全相同**（这正是配对成立的前提）：

| 量 | 值（两 arm 一致） |
|---|---|
| 实测 \|bias\| 均值 | 30.81° |
| 中位 | 31.56° |
| 最小 / 最大 | 0.03° / 59.83° |

**③ `|bias|` 分箱（匹配难度）—— 4/4 全为正**

| \|bias\| 区间 | base | geomA | 差 | n |
|---|---|---|---|---|
| 0–15° | 98% | **99%** | +1 pp | 99 |
| 15–30° | 80% | **85%** | +5 pp | 91 |
| 30–45° | 87% | **92%** | +5 pp | 97 |
| 45–61° | 96% | **98%** | +2 pp | 113 |

分箱互不重叠（近似独立），4/4 同向。增益最大的区域是中等偏难（15–45°）。

## 4. 局限（不可回避）

1. **单 seed 族**：400 个场景全部来自 seed 42…441。p 值是对**这一批场景**的推断，不是对「所有可能场景」的推断。要外推需要多 seed 族（如 seed ∈ {42, 1042, 2042}），成本线性。
2. **只测 `difficulty_level = 0.0`**：目标不规避。d>0 时差异未知。
3. **geomA 是在这个几何下训练的**：+3.25 pp 是「同分布几何」下的增益。n=100 的旧几何数据显示它也能迁移（+3 pp，7 vs 4 不一致对），但那个样本量不足以支撑结论。
4. **多重比较**：本次跑了多个对照。本检验是预先指定的主终点（同几何策略对比），未做多重校正；若要求 Bonferroni 校正到 α=0.0125，p=0.0146 会刚好落在边界之外。**这是判断这个结论稳健性时最需要注意的一点。**
5. JSBSim 物理不可跨机复现，以上数值只在本机 cu126 环境成立。
